# Django E-Commerce Website

A full-featured e-commerce website built with Django.

## Features

- User Authentication
- Product Management
- Category and Subcategory System
- Product Variants (Size & Color)
- Product Search
- Shopping Cart
- Product Comments and Replies
- Like and Dislike System
- User Permissions

## Technologies

- Python
- Django
- SQLite
- Bootstrap
- CKEditor
- django-taggit
